# Design and scientific conventions

## Geometry, primitives, and boundaries

`codes.Code` loads the four matrices from the designated Hex checkout. Qubit indices and all check/logical rows are preserved. It checks binary CSS commutation, logical anticommutation, and GF(2) rank giving one encoded qubit. Distances must be odd integers >=3 and have matrices in that checkout. Coordinates are row-major `(i % d, i // d)`; check supports in H_X/H_Z define the boundaries. surface-sim is used for an independent reference, not as a different geometry in one comparison arm.

All builders use Hex's surface-specific SE functions. Weight-four X checks interact in sorted support order; Z checks interchange the middle two interactions. X checks precede Z checks. Transversal gate fragments come from Hex's native module generator, preserving the legacy noise interleaving. Destructive measurements use the same pre-measurement flip convention. Hex's retired-qubit MR and common M are equivalent: those data qubits are never used again. Check-ancilla MR resets are followed by explicit reset at the next SE. The native adapter verifies equality after normalizing only these reset redundancies, annotations, and identity operations.

`ideal_encoded` explicitly resets the initial data block without noise, then applies Hex's exact stabilizer-tableau encoder. These ideal boundary operations consume no modeled time. This makes the initial-state assumption explicit to signed Stim flow verification; it adds no SE or readout. `noisy_preparation` physically initializes the chosen basis and performs exactly d X/Z rounds. Opposite-basis signs remain raw; the global decoders infer the frame from the full history. Native Hex uses an additional native preparation-repair module at this boundary. The final boundary is always noisy destructive readout, with no appended perfect SE.

## Measurement ledger and detector frame

Each measurement has an absolute index, physical qubit, basis, block, cycle, operation, SE-round index, logical-layer index, and optional physical time. Logical layers count primitive fragments, not hardware time. SE-round indices increase for each block round; per-block/phase counts are stored independently.

Every known CSS check sign is a set of earlier measurement indices. XOR is set symmetric difference. The initial opposite-basis preparation check has an unknown sign and emits no standalone detector. Once measured, its actual record represents the sign. Under CX(c,t), X_c and Z_t signs become the products of their respective control/target signs. This propagation generates cross-block detectors and cancels intrinsic random preparation outcomes. Destructive measurement parity closes the corresponding check against its propagated sign.

For a post-gate SE group, first form output comparisons `delta_out = y + T_CX old`. Then emit `delta_pre = T_CX^{-1} delta_out` in the **pre-gate frame**. CNOT is its own inverse. Concretely, XOR the X-target comparison into the X-control comparison and XOR the Z-control comparison into the Z-target comparison, check by check. This is an invertible row transformation and changes no quantum operation or raw sample. The measured output signs remain unchanged for propagation to the next layer. Tests verify every detector and terminal observable as a signed Stim flow.

One selected-basis L0 is included. For Z memory it is final Z parity XOR every raw A-Z Bell parity; for X memory it is final X parity XOR every raw D-X Bell parity. Intermediate Bell outcomes are never declared individually reliable. Strict Stim extraction (`allow_gauge_detectors=False`, `approximate_disjoint_errors=False`) and signed observable backpropagation are construction requirements. Invalid circuits cannot trigger decoder fallback.

## Decoders

Global BP-LSD consumes every deterministic detector row, including both CSS sectors, and one shared variable per independent undecomposed DEM error mechanism. Separator components are XORed within that event. Repeated targets cancel. Identical complete detector/logical supports merge by XOR probability, not addition; different logical labels stay distinct. Repeat/shift expansion uses Stim's flattened DEM. Fully trivial events are counted and omitted because they change neither syndrome nor observable. Detector-free logical terms are retained; independent-prior MAP chooses each such fault when q>=1/2. Their contribution remains in physical truth. q=0/1 variables are fixed and removed from the backend with explicit syndrome/logical offsets. Final syndrome residual, BP convergence, and logical success are different quantities. BP-LSD residuals use all detector rows. Native residuals use the legacy engine’s preparation-detector converter; matching adapters report null residuals because they expose logical predictions rather than a complete fault-vector estimate.

The installed ldpc adapter loops over shots; `schedule: parallel` describes BP updates, not process parallelism. Parameters are validated and passed to the installed API. Public convergence/iteration counters are recorded. Expensive cluster statistics are collected only in separately timed diagnostic replays with `reset_cluster_stats` and `set_do_stats`, then disabled. LSD is approximate fault inference, not exact logical maximum likelihood.

SE PyMatching uses strict graph decomposition. LOM uses `MoMatching(dem, dem_subgraphs, det_inds_subgraphs)` and `get_circuit_subgraph`. Its observing-region policy is the **complete selected CSS-sector superset** across all blocks, including preparation, both Bell branches, and terminal closure. A CNOT preserves Pauli type, so this contains the observable's entire relevant sector; it intentionally retains more checks than a minimal region. Local detector IDs map to ascending global IDs; L0 remains L0. The reference test separately exercises the upstream automatic observing-region extractor in the documented unrotated pre-gate example. Custom circuits do not rely on noise-dependent boundary errors to discover regions, so p=0 is supported.

Each selected subgraph must decompose strictly into graphlike components. No hyperedge is silently dropped. `on_nonmatchable` either errors or selects a named global BP-LSD decoder for the entire case. Only the dedicated decomposition/support exception allows fallback. If that effective decoder was already selected, samples and decode calls are reused, with aliases in `cases`. These MoMatching calls use ordinary PyMatching; **edge correlations are not enabled**. Graph decomposition alone is not correlated matching. LOM can correlate histories across blocks without enabling PyMatching edge-correlation reweighting.

Native Hex uses the existing `css_detector_module.c_func`, Bell `c_func`, final-readout `c_func`, and `correction_to_measurement_flips`. Sampling is physical Stim sampling first; inferred corrections update records once afterward. No preparation-sign commitment or separate code-capacity stage is inserted into either AFT decoder. Native output is translated into the common raw-observable frame using raw measurement parities; sampled actual logical truth is never passed to inference. Default native priors remain exactly the legacy policy, including its existing check-matrix weights. With the optional explicit noise profile, this is deliberately still the `hex_legacy_at_sweep_p` prior model and is separately recorded; it is not retuned to the new idle/one-qubit rates.

## Noise and actual schedule

`hex_legacy` includes independent preparation/readout flips of p and two-qubit depolarization of p. It omits explicit idle and one-qubit-gate noise. Elapsed time and spacetime volume are null; gate counts are not treated as time.

`explicit` rebuilds noise exactly once from the ideal primitive operations. Provide nonnegative multipliers for p1, p2, reset, measurement, idle, plus positive durations for the first four classes and a named `time_unit`. All resolved probabilities must be <=0.5. Each two-qubit pair is a serial physical layer, including pairs that Stim coalesces into one instruction; reset, measurement, and one-qubit instructions act in parallel on their target list. No two-qubit concurrency is inferred from instruction grouping. This conservative schedule follows the actual Hex order. Every physical layer, its targets, live blocks, idle qubits, duration, and start is saved.

`preparation_schedule: serial_wait` prepares A then B. D waits with the declared idle noise, and A waits during B preparation. No ideal factory or overlapping preparation is assumed. All allocated data/check qubits within live blocks count toward resources and idle exposure. Hardware IDs are reusable in principle; fresh simulator block indices are used for clarity. Peak live hardware is one block for SE and three for Knill, rather than the largest simulator index. Spacetime is the integral of active physical qubits over the saved schedule.

For idle depolarization p_i per time unit, a layer of duration t uses `3/4 * (1 - (1 - 4*p_i/3)^t)`, the composed depolarizing channel. Equal-cycle comparison is primary. Equal-time requires this explicit schedule and a `target_time`. It chooses the largest whole number of cycles not exceeding the target, or one cycle if the target is too short, rebuilds the actual schedule, and records the signed residual mismatch. It never pads with undeclared operations.

## Processes, stopping, and timing

Independent physical work IDs are `(sampling_case_id, replicate, chunk_id)`. SHA-256 derives separate physical, timing-selection, and retention streams. Decoder parameters and worker count are excluded from physical sampling identity. Fixed batch partition, pinned environment and platform are required for bitwise comparisons; no cross-Stim-version/SIMD guarantee is made. A bounded spawn pool admits at most workers × pending-per-worker tasks; the default pending limit is one per worker. `sampling.model_cache_size` bounds compiled models per worker and defaults to one, including when the configured bound decreases on a cache hit. Hex local transitions use a 16-entry LRU cache. Repeated Hex state-preparation modules use one local template per basis and share its DEMs, sparse maps, and decoder handles; their circuits and correction locations are remapped to each support. Timed matching callbacks hold a weak owner reference so an evicted native model can be released. Global BP-LSD retains only active CSC matrices and compact diagnostics; its `active_sparse_matrix_bytes` estimate sums CSC data, indices, and pointer buffers. Live native objects are never pickled across processes.

`prepare()` writes circuits, DEMs, strict decomposed matching graphs, structural decoder descriptors, and hashes. It resolves configured LOM fallback, but constructs no live PyMatching, MoMatching, BP-LSD, or Native Hex decoder. Non-native workers load the saved circuit/DEM, matching graph, and ledger, then construct only numerical backends. Native Hex reconstructs its structured module pipeline once per worker model. Each worker writes its own staged Parquet files and returns a small manifest with identity, row counts, hashes, and resource measurements. The parent validates staged files, bounds retained failures, promotes parts in deterministic submission order, then writes the checkpoint JSON as the final transaction marker. Resume validates matching graph hashes, removes orphaned partial transactions, and retries the same task/seeds. Explicit worker-failure logs preserve assigned shot counts. A failed worker contributes unobserved assigned shots as computational task failures in decoder tables; its sampling table has zero confirmed shots and a separate requested count. Such a run is marked failed. Retry replaces those parts, rather than double counting them. Pending, unattempted work is not presented as observed data.

Fixed shots is primary. Target-error stopping uses the explicitly named reference decoder's logical plus computational failures and may overshoot by one committed chunk. Already-running excess results are discarded. Time budget is a cumulative run-wide wall budget, excluding artifact preparation but including workers/model setup and shutdown; excess work is recorded and discarded consistently. Resume preserves accumulated active wall time. Intervals under either sequential rule are labeled descriptive Wilson intervals without a sequential coverage guarantee.

Native Hex requires raw measurements and samples through `compile_sampler` plus the measurement-to-detector converter. PyMatching, MoMatching, and global BP-LSD require detectors/observables only and use `compile_detector_sampler`, avoiding the raw measurement matrix. The same fixed seed produced matching detector/observable arrays for tested Stim circuits; no cross-Stim-version equivalence is claimed. Throughput timers enclose actual batch adapter calls after sampling and warm-up. Individual latency timers enclose separate actual `decode_one` calls on a deterministic uniform subset, selected across all replicates. Raw-record conversion is separately timed; detector sampling performs conversion internally. Native backend calls, inclusive module totals, and frame propagation are nested records; do not sum parent and child timings. Instrumentation overhead is included in enclosing native timings and disclosed. Summed service work is not a parallel critical path. Additional one-worker replay uses retained uniform samples and labels replay/load status separately from production observations.

Failure retention is bounded across all replicates of a sampling case. Uniform retention is independently selected across the full fixed maximum workload. Native retained samples include raw measurements; detector-only retained samples have null raw measurements and retain the detector/observable bits needed for decoder replay. Optional all-syndrome storage is incremental Parquet; the parent filters its staged part in bounded Arrow batches, including when every syndrome is saved. Worker replay and retention loops visit only selected shot indices unless all-syndrome storage is requested. Shot rows are built columnwise; `save_shot_results=false` omits them and stores paired decoder counts in `paired_chunks`, so aggregate analysis still works. `sampling.chunk_size` is user-controlled and validated as at least one; chunk array memory scales approximately as `chunk_size × per-shot record bytes`. No automatic resizing occurs. For d=7/N=7 Native Hex, measured per-shot raw and detector arrays have 4,095 and 3,384 Boolean bytes. The corrected-record copy adds another 4,095 bytes, so those three arrays alone need about 23.7 MB at chunk size 2,048 or 47.4 MB at 4,096, before decoder scratch, outputs, and Arrow buffers. These are advisory lower bounds, not a capacity guarantee. The main remaining native hotspot is the full corrected measurement-record copy used for residual verification. Stim's converter requires the complete corrected Boolean measurement array. A packed local-delta, in-place correction and restore prototype used less extra buffer space but was slower in the measured d=7/N=7, 16-shot case; the production path keeps the simple copy and never mutates caller records. Case/model metadata and batch/timing tables are read into memory during analysis; they scale with cases/chunks, not total physical-shot vectors.
