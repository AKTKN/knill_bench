# Deep Clifford generation Phase 3 report

Implemented on feature/converter-simulations after Phase 2 b1332b8. Converter
457dc519, stimflow ffe0d043, Stim 1.16.0, PyMatching 2.4.0 and all dependency
sources remain unchanged. Work uses Conda knill_system. No Hex runner or
existing converter memory physics is modified.

## Delivered behavior

The seeded abstract generator records every logical gate and its RNG
convention. Uniform H/X/Y/Z draws precede a shuffled perfect CNOT pairing with
independent direction coins. Only qubit count, depth and circuit_seed determine
this instance; d/p/n_r, master_seed, resources and workers do not consume the
logical stream. Default depth is 32 on four logical qubits.

The LSTIM consumer emits ideal parallel plus-state initialization, full gate/
CNOT/QEC barriers and n_r parallel native KNILL_EC(d) groups per interval.
Unique resource handles/labels implement three-patch rotation per persistent
Q handle. All four factories overlap in native time-layer metadata. Exactly
4*depth*n_r relocations use twelve patches; no surviving Q is reset during
rebinding. The last interval is followed by one parallel noiseless final SE
round on each output. No geometry or quantum noise schedule is recreated.

Both noisy d-round resources and public typed ideal/M9 resources are supported,
with a fixed optional p_st multiplier. Input remains ideal. Production obtains
logical_output_stabilizers from the converter, validates their abstract rank/
commutation and calls make_terminal_observable_probe. All physical lifting,
MPP targets, relocation and signed frame semantics remain native. The exact
exported circuit is probe.circuit, retaining its canonical prefix boundary,
terminal indices, source fingerprint, signed supports and use IDs.

`knill-bench-v2 compile CONFIG` publishes exact LSTIM/extended Stim, signed
logical definitions and native/full-sequence/probe metadata under a distinct
converter_generation_v1 root manifest. It does not sample, build a decoder,
write Parquet or mark a scientific run complete. Failed compilation records a
failed generation. Noisy deep run/resume remains explicitly guarded for Phase 4.

## Evidence and bounds

New public-only consumer tests independently construct the four-qubit ideal
Stim circuit and conjugate initial X generators. They compare complete signed
stabilizer groups, allowing equivalent bases. They also test physical lifecycle
epochs, every relocation chain, intermediate output orientation/binding, full
barriers, parallel resource overlap versus serialized factories, typed noise,
ideal boundaries and exact probe measurement partition.

Noiseless d3 depth-2 and depth-3/n_r=2 samples have at most seven shots. A
test-only exact enumeration of 512 physical X/Z patterns selects a representative
for perfect recorded sectors and prepared logical constraints, then applies
native frame corrections. The corrected intended terminal outcomes agree.
Flipping only terminal columns leaves all selected corrections unchanged.
This validates the noiseless frame boundary, not a noisy decoding algorithm.

Finite-p d3/5 circuits compile and preserve the same logical instance. The
requested d3/depth-32 configuration compiles/validates with twelve patches and
128 teleportations, without sampling. New data-only LSTIM fixtures are exported
from the pinned public depth-2/3 examples and hashed. Comparisons use structural
and independent signed-state invariants; the reference example's extra
post-CNOT Paulis are not substituted into the requested gate ordering.

The baseline converter gate passes 181 tests. The config/generator gate passes
169 tests, and the artifact/CLI gate passes 10. The initial physical gate has
16 passes and one test-only round-index assumption failure: native round
indices continue across a patch use. The corrected test checks a single round
with d²-1 records and passes in isolation. The initial artifact tests also
corrected a ConfigDocument.source assumption to its actual source_path API.
The final full regression passes **902 tests**, with **1356 inherited warnings**,
in **661.25 s**. All 17 deep physical checks, the actual depth-32 template and
every existing Hex/v1/converter SE/Knill regression pass. Exact commands and
the test-only corrections are recorded in [TEST.md](../TEST.md).

Installed CLI compile checks pass both resource policies at d3/depth 1, with
no sampling or error tables. Run/resume refusal preserves generated bytes.
All 19 pre-change non-deep config hashes, physical point IDs and point seeds
remain identical. Six project wheels build with all 72 Hex matrix resources
and the converter grammar. With PATH empty and imports verified under the
installed target, both policies compile and retain the run/resume guard.
These checks use existing Conda numerical dependencies, without provisioning
a new offline Python environment. pip check, compileall and source/dependency
integrity checks pass.

The circuit family uses Knill cycles in place of the reference SE intervals;
its physical noise is the converter uniform policy. No noisy deep LER,
correlated decoder, threshold, performance or paper-agreement result is claimed.
